Why you will like it

The whole title, every time

Long titles are shown in full instead of ending in “…”. You never have to hover to read the rest.

Works across YouTube

Works on the home page, search results, channel pages, playlists and the suggestions next to a video.

Nothing to set up

Install it and you are done. No settings, no account, no buttons to press.

Light and focused

It only changes how titles are displayed, and it runs only on youtube.com.

Questions and answers

Is it free?

Yes. YouTube Full Title For Videos is free to use.

Will it slow YouTube down?

No. It adds a single small style rule to the page and does nothing else.

Which browsers does it work in?

It is built for Chrome. Browsers that install extensions from the Chrome Web Store, such as Edge, Brave and Opera, usually run it too.

A title is still cut off. What should I do?

Refresh the page first. If it is still cut off, YouTube has probably changed its layout. Please report it on the support page.

What data does it collect?

None. The extension does not collect, store or send any personal data.
