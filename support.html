Support

Help with YouTube Full Title For Videos: quick fixes first, then how to report a problem.

Titles are still cut off

  • Refresh the page. YouTube tabs that were open before you installed the extension need a refresh.
  • Check that the extension is on. Open chrome://extensions and make sure YouTube Full Title For Videos is enabled.
  • Check site access. On the same page, open the extension's details and make sure it is allowed to run on youtube.com.
  • Try without other YouTube extensions. Another extension that restyles YouTube can override the titles. Turn the others off one at a time to find the one that conflicts.

YouTube changes its page layout from time to time. If titles are cut off only on one kind of page (for example search results), the extension probably needs an update. Please report it.

Report a problem

Open an issue on GitHub and include:

  • the page where the title is cut off (home page, search, a channel, a playlist, next to a video);
  • a screenshot;
  • your browser and its version.

Report a problem on GitHub

You need a free GitHub account to open an issue.

Common questions

  • Does it work in other browsers? It is built for Chrome. Browsers that install extensions from the Chrome Web Store, such as Edge, Brave and Opera, usually run it too.
  • Is there anything to set up? No. There are no settings and no account.
  • How do I remove it? Right-click the extension's icon and choose "Remove from Chrome", or remove it from chrome://extensions.
  • What data does it collect? None. See the privacy policy.
