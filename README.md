# YouTube Full Title For Videos

Website for the YouTube Full Title For Videos Chrome extension.

Live site: https://pageereel-stack.github.io/fulltitle/

- `index.html`: home page
- `install.html`: welcome page the extension opens after it is installed
- `privacy.html`: privacy policy
- `support.html`: help and problem reports
- `site.js`: settings (video, Chrome Web Store link) and language switching
- `locales/`: translations
